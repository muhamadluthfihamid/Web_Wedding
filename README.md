# Web_wedding_invitation
 Web undangan digital menggunakan Framework Laravel 11, dan admin menggunakan template sb-admin2.
Cara ambil projek
1. donwload terlebih dahulu atau clone projeknya
2. ekstrak projek nya
3. buka file yang sudah di download bisa menggunakan vscode
4. ketikan perintan composer update
5. kemudian salin file .env example atau ubah file tersebut menjadi .env
6. kemudian ubah nama username database kalian dan masukan passwordnya di file .env
7. ketikan perintah php artisan key:generate
8. kemudian ketikan php artisan migrate
9. dan jalankan projeknya dengan mengetikan php artisan serve
10. enjoyy!!!
